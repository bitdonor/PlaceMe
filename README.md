# PlaceMe
Приложение для рассадки участников олимпиад по аудиториям. Создано, чтобы сократить рутинную работу при распределении учеников (по аудиториям / за столами). Работает так, чтобы минимизировать штрафы за соседство, построен на 3-х алгоритмах (модифицированные жадный, отжиг, генетический).
