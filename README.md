## Что это

PlaceMe — десктопное приложение, которое **автоматически рассаживает участников олимпиады** по аудиториям так, чтобы минимизировать нежелательное соседство: одноклассники, параллели, участники одной школы или с одинаковым критерием знакомства должны сидеть как можно дальше друг от друга.

Это одновременно и рабочий инструмент для организаторов, и исследовательская площадка: внутри реализованы и сравниваются **три алгоритма** — жадный с локальным поиском, имитация отжига и генетический (все три достаточно сильно модифицированы и оптимизированы под задачу рассадки).

## Для кого

- **Организаторы олимпиад и конкурсов**, которым нужно быстро распределить сотни участников по местам без ручной работы.
- **Преподаватели и методисты**, готовящие зачёты, контрольные и соревнования.
- **Студенты и исследователи**, изучающие метаэвристики и задачу квадратичного назначения (QAP).

## Как работает

1. Вы задаёте **конфигурацию аудиторий** — сколько залов и как в них расставлены места (визуальный редактор сетки).
2. Загружаете **список участников** из Excel (`.xlsx`).
3. Опционально прогоняете **валидатор**, который находит дубликаты, похожие имена и пустые поля.
4. Нажимаете **«Рассадить участников»** — программа запускает все три алгоритма, выбирает лучший результат и сохраняет готовые Excel-файлы.
5. При желании запускаете **тестирование** — 10 прогонов каждого алгоритма + HTML-отчёт с графиками сходимости и стабильности.

## Ключевые возможности

- 🔧 **Визуальный редактор аудиторий** — рисуйте сетку мест мышью, undo/redo, зум, панорамирование.
- 📥 **Загрузка из Excel** с автоматическим определением столбцов (русские заголовки).
- 🛡️ **Валидатор входных данных** — дубликаты ФИО, похожие имена (Левенштейн), пустые поля, похожие названия школ.
- 🧮 **Три алгоритма** с единым интерфейсом и возможностью запуска по отдельности или всех сразу.
- 📊 **Сравнение алгоритмов** — HTML-отчёт с графиками сходимости, стабильности и состава штрафов.
- 📤 **Экспорт в Excel** — вахта, по аудиториям, «для учителя» (с сохранением исходного порядка строк).
- 💾 **Портативная сборка** — один `.exe` и папка с ресурсами, без установки.

## Модель штрафов

Чем меньше итоговый штраф — тем лучше рассадка. `0.0` означает идеальную рассадку: ни один участник не сидит рядом с одноклассником или знакомым.

### Соседство

Штраф считается **только** для непосредственных соседей — клеток на расстоянии не больше 1 по строке и столбцу:

- **Боковое соседство** (лево, право, спереди, сзади) — коэффициент **1.0**
- **Диагональное соседство** — коэффициент **0.5**

Если между участниками **пустая клетка** (место отсутствует в конфигурации) или расстояние **больше 1 клетки** — штраф **не начисляется**. Каждая пара соседей считается только один раз.

Итоговый штраф за пару = `базовый штраф × коэффициент соседства`.

### Базовый штраф

Критерий знакомства проверяется в первую очередь — он перекрывает всё остальное.

| Ситуация | Базовый штраф (боковое соседство) | Диагональное соседство |
|---|---|---:|
| Одинаковый непустой критерий знакомства | **70** | **35** |
| Один класс, одна буква (одноклассники) | **70** | **35** |
| Один класс, разные буквы (параллель) | **30** | **15** |
| Одна школа и один город, разные классы | **10** | **5** |
| Разные школы или разные города | **0** | **0** |


## Алгоритмы

| Алгоритм | Ключевая идея |
|---|---|
| **Жадный с локальным поиском** | Мультистарт (10 попыток) + итерированный локальный поиск (перемещения + свапы). |
| **Имитация отжига** | Критерий Метрополиса, адаптивная температура, guided selection по нарушителям, инкрементальный пересчёт дельты. |
| **Генетический** | Кодировка индексами мест, турнирная селекция, OX-скрещивание, адаптивная мутация, элитизм, локальный поиск. |

Перед каждым запуском вычисляется **опорный максимум** (через отжиг на максимизацию) — практическая верхняя граница штрафа, относительно которой показывается «% от max».



## Критерий знакомства

**Критерий знакомства** — самый гибкий инструмент разделения. Это произвольная текстовая метка, которая позволяет гарантированно рассадить конкретных участников подальше друг от друга, **независимо от школы, класса и города**.

Принцип прост: **два участника с одинаковой непустой меткой получают максимальный штраф при соседстве (70)** — такой же, как у одноклассников. Если метка пустая или метки разные — этот критерий не срабатывает.

### Когда использовать

- Чтобы разнести по разным концам аудитории участников **одной тренировочной группы**, **команды** или **кружка**.
- Чтобы разделить **друзей**, которые могут списывать.
- Чтобы обеспечить рассадку **по разным версиям заданий** (метка = номер варианта).

## Технологии

- **Python 3.12**
- **PyQt6** — графический интерфейс
- **pandas** + **openpyxl** — работа с Excel
- **matplotlib** + **numpy** — графики в отчёте
- **PyInstaller** — сборка в `.exe`

## Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/PlaceMe.git
cd PlaceMe

# 2. Создайте виртуальное окружение и установите зависимости
python -m venv .venv
.venv/Scripts/pip.exe install -r requirements.txt

# 3. Запустите приложение
.venv/Scripts/python.exe main.py
```

## Сборка в .exe

```bash
.venv/Scripts/python.exe build.py
```

Результат — папка `Release/` с `PlaceMe.exe`, иконкой, `manual.html` и конфигурациями. Вся папка переносится без установки.
